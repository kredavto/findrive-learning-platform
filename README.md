# ФИНДРАЙВ Академия

Интерактивная обучающая платформа для амбассадоров ООО МКК «ФИНДРАЙВ».

## Возможности

- 13 модулей обучения с прогрессом и контрольными заданиями;
- практикум по лестнице Ханта, SPIN-продажам и работе с возражениями;
- сценарии коммуникации, карточки лидов и калькулятор вознаграждения;
- матрица допустимых формулировок и реестр источников;
- адаптивный интерфейс в фирменной чёрно-золотой гамме.

## Запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Технологии

React 19, Next.js 16, vinext, Cloudflare Workers/D1 и Drizzle ORM.
